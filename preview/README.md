v1.2 is a content update using the v1.1 editorial design. The homepage contains
three selected projects and four selected publications. Full content remains
in the archives. The private source CV is not included.

For a working preview, download **eunji-woo-preview.zip** using GitHub's
**Download raw file** button. Extract the ZIP, then double-click
**Eunji-Woo-Preview.html**. It opens in a browser without installing anything.
Site content, styling, and page navigation are included in the file. The older
public CV PDF is deliberately not embedded; the preview points to the updated
CV page instead.

These are review files on a separate branch. The live website is unchanged.
The `preview` directory is excluded from the Jekyll build.
