# Website preview

- [Desktop screenshot](homepage.png)
- [Mobile screenshot](mobile.png)

For a working preview, download **eunji-woo-preview.zip** using GitHub's
**Download raw file** button. Extract the ZIP, then double-click
**Eunji-Woo-Preview.html**. It opens in a browser without installing anything.
All content, styling, page navigation, and the CV are included in the file.

These are review files on a separate branch. The live website is unchanged.
The `preview` directory is excluded from the Jekyll build.
